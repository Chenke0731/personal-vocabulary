# 个人英语词汇学习软件设计

日期：2026-10-28。状态：设计已整理，等待用户评审；尚未开始产品实现。

## 1. 已确认的目标

- 用户已通过六级，成绩约500分。
- 六级高分与考研词汇强化为双主线，补充刘洪波《雅思词汇真经》。
- 每天使用15—30分钟，主要在手机学习，希望学习进度跨设备同步。
- 涉及《考研英语词汇红宝书》、六级词汇和刘洪波《雅思词汇真经》。用户没有电子资源，已授权搜索候选来源。
- 用户认可前述方案，进入具体设计阶段。

成功标准：手机打开即可开始一段可中断的学习；任务量随复习负担调整；跨书学习共享对应知识点的记录；断网作答可保存；同账号不同设备最终获得一致的记录和复习安排。

## 2. 第一版设计选择与假设

| 事项 | 第一版决定 | 依据与限制 |
| --- | --- | --- |
| 产品形态 | 手机优先的PWA，电脑浏览器同样可用 | 只维护一套客户端；实际安装与音频表现须真机验证 |
| 云端 | Supabase Auth、PostgreSQL与私有Storage | 避免自建账号服务；必须先验证用户手机网络可达性，再投入完整同步开发 |
| 前端 | React、TypeScript、Vite | 适合小型交互应用；实现时锁定依赖版本 |
| 本地数据 | IndexedDB，通过Dexie访问 | 支持离线词包、作答及待同步队列 |
| 复习算法 | 使用ts-fsrs，锁定算法、参数与实现版本 | 初期采用默认参数，目标记忆率初值0.90；它不是个人学习效果保证 |
| 账号 | 邮箱与密码登录，支持密码找回 | 私人使用，部署时关闭公开注册；账号初始化和恢复邮件需要真实环境验证 |
| 时间 | UTC保存时间，按Asia/Shanghai划分学习日 | 出国或改变时区时可手动更改展示时区，不改变历史作答时刻 |
| 考试日期 | 第一版不要求填写 | 用户尚未给出考试日期，不生成虚构的倒计时或清单完成承诺 |
| 词书版本 | 候选资源的明确版本分别标注 | 不把2026社区红宝书数据称为其他年份原书 |

这些属于设计默认值，可在评审时调整，不代表用户已单独选择某个云服务或同意费用。

曾比较的路线：Anki词包最快验证学习内容，但难以统一定制流程；原生手机与电脑应用增加维护工作。选择独立PWA是为了满足当前个人使用、短时学习和双端同步的组合需求。

## 3. 第一版范围

交付：账号登录、短测、词包导入与管理、今日任务、学习卡片、间隔复习、听辨和拼写练习、薄弱项、生词收藏、基础统计、自动同步、数据导出和恢复。

不加入排行榜、社交、付费系统、公开词库市场、AI聊天老师、发音评分和完整模考。AI不是第一版运行依赖。软件不能以背词进度直接预测六级或雅思分数。

## 4. 手机页面与学习流程

底部四个入口：今日、词库、薄弱项、我的。

### 今日

- 主按钮为“开始15分钟”，展示预计时长与可学习任务量。
- 完成核心任务后可选择再学15分钟。
- 单卡片布局；翻答案、评级和下一题位于拇指容易触达的位置。
- 做完当前题后可随时结束。已完成作答立即本地保存，中途退出不丢失。
- 15分钟是时间预算，不要求到点强制截断当前题；超时不自动添加新词。
- 刷新、切换页面或重开应用不会重复补发当天的新词额度。

### 词库

- 按来源书籍、可核实的章节/词群浏览，支持单词搜索。
- 每条显示来源版本、核心义项、搭配、音标，以及可用的例句与音频。
- 无可核实章节的数据按“未核对原书章节”展示，不能生成仿真的原书目录。
- 支持CSV/JSON词包导入；导入前预览有效条数、重复项和问题项。
- 可下载词包和实际可用的音频供离线学习；未下载的音频不标为可离线。

### 薄弱项

按反复遗忘、听辨不稳、拼写困难及语境辨义困难查看。每项进入对应练习；听辨失败不清空已积累的认义表现。

### 我的

学习预算、时区、账号、同步状态、词包管理、统计、导出和恢复。

同步状态只显示用户需要的信息：“已同步”“有N条待同步”“需要重新登录”或“同步失败，点击重试”。技术日志放在可展开的诊断详情中，并去除凭证。

## 5. 初始测评与任务量

初次安装可先体验示例；正式个性化从一段不超过约10分钟的小测开始，允许中途退出后继续。

初测抽取24个知识点，基础、六级和考研/雅思候选内容各8个；认义为主，加入少量听辨和拼写。没有下载音频时跳过听辨并明确该能力尚未评估，不把未测试记为错误。

输出抽样正确率与各能力的初步表现，不推算考试分数或精确词汇量。不因一次正确就把整本书相应词条标为掌握。初测数据和正式复习记录分开；初测后抽查通过的内容可进入一次延迟复核。

每日以15分钟为默认预算，可延长到30分钟：

1. 优先到期复习，按到期程度与薄弱情况排序；同一项只出现一次待办入口。
2. 用剩余预算安排新知识点；起步目标每天最多6个，初始上限8个。
3. 新点优先目标书籍重合且尚未掌握的内容，再分配六级与考研专项；每累计10个新点，最多1个来自仅雅思补充层。
4. 同一词的新义项也占一个新点额度，不能通过拆分义项绕过预算。
5. 估时初值为复习20秒、新点60秒，随后使用最近7个学习日同题型有效作答耗时的中位数。超过120秒的停留不用于估时。
6. 复习预计占满预算时，当天新增为0。暂停、切到后台的时间不计入学习时长。
7. 至少有3个学习日后才自动调整新点目标；过去7天计划完成率低于80%时减2个，完成率达到90%且延迟认义回忆成功率达到85%时加1个。增加目标还需至少20次有效延迟认义回忆；样本不足时不增加。目标范围为0—8个；用户仍可结束学习。
8. 上述阈值均为待个人试用验证的产品启发式规则，不是研究结论。

离开几天后按当前预算分批消化积压，显示剩余数量；不把全部积压强塞进一天，也不悄悄删除到期项目。

## 6. 知识点与学习记录

### 内容关系

- Lexeme：语言、规范拼写和经核实的英美拼写别名。保留原始拼写。
- Sense：某个词的具体义项、词性、释义及来源。
- Expression：搭配或短语，关联涉及的词与义项。
- BookMembership：某本书某个版本中的原始条目、章节/词群与对应知识点。
- Exercise：认义、听辨、拼写、语境练习中的一种。

同一个Sense可对应多本书。相同拼写而不同词性/义项不能仅按单词字符串合并；短语不能拆成一组普通单词而丢失整体意义。

英文大小写、首尾空格可用于提出重复候选；专名和有区别的大小写保留。英美拼写、词形变化和近义词需要经核实的映射，不能自动视为同一个词。

### 进度单位

复习卡的身份为“知识点ID＋能力类型”。认义、听辨、拼写、语境分别保存表现。各书进度引用这些卡片，不能维护彼此独立且可能矛盾的掌握计数。

默认先为目标Sense建立认义卡。听辨或拼写仅在该词被选为专项内容时建立，避免词库一导入就生成四倍任务。

统计区分：来源记录数、不同拼写数、知识点数、已练习数、抽查结果、延迟回忆成功率、待复习数。覆盖率只针对已导入的对应版本；内容尚未核对完整时显示“已导入内容覆盖”，不显示“全书完成”。

### 作答与调度

- 先主动回忆，再展开答案；认义按“忘记/困难/记得/轻松”评价。
- 忘记对应失败；困难表示回忆成功但吃力。界面提供简短说明。
- 拼写先自动判断：去首尾空格、按题目要求处理大小写，接受经核实的拼写别名；不把语义不同的词作为别名。
- 自动判分后允许纠正误判。第一次提交即固定本地事件，纠正追加撤销/替代事件，不悄悄覆盖原记录。
- 同一事件的双击、刷新重试和网络重传使用相同ID，只计一次。
- 保存算法版本和参数版本，使本地和服务器能对同一事件集合生成一致安排。第一版关闭随机抖动，以保证重算结果可复现。
- 短时间内再次展示属于短期练习，不能进入“延迟回忆成功率”的分母；该统计只计距离同能力上一次展示至少24小时的正式回忆。

每份词包附source-manifest：来源URL、抓取日期、仓库提交/文件SHA、标注版本、原始记录数、校对状态、来源许可说明、内容校验值。教材内容的使用范围与仓库程序代码许可证分别记录；不推断出版社授权。

初期完整候选词表可进入私有待校对区；正式每日任务仅使用已检查的核心义项和练习内容。词包在用户账号私有范围管理，不发布公开下载入口。云端上传前核实对应内容使用范围；不能确认可云端存放的内容保留本机，跨端仅同步稳定知识点ID和学习记录，并提示另一设备需导入相同词包。

校对顺序：结构验证→拼写/重复候选→抽查词义与音标→优先审阅会进入近期任务的内容→扩大样本。对第三方例句另行检查，不能把机器生成内容标为原书例句。

每次词包升级保留稳定知识点ID。文字勘误不重置学习；新增义项建立新ID。拆分或合并需带映射表，迁移前备份，不能用导入顺序作永久ID。

## 8. 架构与职责

应用分为六个小模块：

| 模块 | 职责 | 输入/输出与边界 |
| --- | --- | --- |
| content | 词包验证、来源映射、搜索 | 接收带清单的词包，输出稳定内容ID和问题报告，不安排复习 |
| learning | 呈现题目、反馈和保存作答 | 使用内容ID并生成事件，不直接操作云端 |
| scheduler | 复习状态、今日队列、时间预算 | 从事件和算法配置推导队列；不依赖UI |
| storage | IndexedDB事务、离线词包与待上传队列 | 一次事务同时保存作答和待同步项，防止只存其一 |
| sync | 登录态、增量上传/拉取、重试、状态呈现 | 同步事件和私有设置；失败不阻塞本地学习 |
| insights | 书籍覆盖和能力统计 | 读取事件和内容映射，不另建一套掌握状态 |

共享调度模块在客户端与服务器使用相同版本。生产前端以HTTPS托管；云服务项目与托管位置需通过手机Wi-Fi、移动网络及电脑浏览器实测后确定，不能假设在用户网络下可用。

## 9. 自动同步与冲突规则

### 保存与上传

1. 首次登录并联网完成账户和词包准备，随后允许离线学习。
2. 每次作答先写本地事务：review_event与outbox同时成功才进入下一题；失败时保留当前题并提示重试。
3. 应用打开、回到前台、应用内网络恢复、完成一组任务及手动重试时触发同步。
4. 上传批次逐条以账号ID＋事件ID去重；服务器确认接收后才清除对应outbox项。请求超时按原事件ID重试。
5. 上传成功后拉取服务器新增事件并重算本机相关卡片。分页期间保留旧游标，全部落盘成功后才推进游标。

### 顺序与离线冲突

- 作答保存设备ID、UTC发生时刻、服务器接收时刻和上次校准的设备时差。
- 首次联网采集服务器时间用于估计设备时差；有效作答时间使用该差值修正，不随每次上传重新漂移。
- 同一批有效事件按有效发生时间、事件ID稳定排序，使用锁定配置重新推导状态。超过服务器接收时刻5分钟的未来事件以接收时刻为有效上限，并标注时间修正。有效时刻在首次接收时固定，重复上传不能改变它。
- 两设备离线作答同一卡片时，全部历史保留，任何一端都不能直接上传整份本地掌握快照覆盖另一端。
- 同一卡片、同一基础调度修订号生成的并发作答视为一个冲突组：保留原始作答，调度只采用其中最保守的有效评级；同评级选最早有效时间，再以事件ID打破平局。组内其他记录显示为重复练习，不增加延迟回忆分母。
- 已在本机看到前一次作答后再做的练习有新的基础修订号，不归入同一个冲突组。
- 服务器分配递增同步序号并在事务内更新推导状态；同账号并发上传串行处理。客户端同步后使用服务器确认的统一修订号。
- 设置逐字段按服务器接收顺序覆盖；收藏和取消收藏保留操作记录并采用同样规则。界面避免要求用户手工合并技术冲突。

### 登录、退出与数据恢复

- 会话过期时继续本地保存，提示重新登录后上传；不将待同步记录归给另一个账号。
- 本地数据按账号隔离。退出有未同步内容时先提供同步或导出，不能静默清除；清除本机数据是独立明确操作。
- 云端同步成功的记录可在新设备恢复；尚未同步且本机数据丢失的记录无法由云端恢复，状态说明需清楚。
- 关闭应用后的后台同步只作浏览器支持下的增强，不作为可靠性前提。

## 10. 云端数据与访问边界

最小表：profiles、private_content_packs、review_events、card_states、user_operations。词包文件在私有Storage；内容ID和调度状态关联对应词包版本。

- profiles保存预算、时区和算法参数版本。
- review_events保存不可变作答与撤销/替代关系，约束同账号事件ID唯一。
- card_states为可重建缓存，包含服务器修订号；客户端不能直接覆盖。
- user_operations保存收藏、设置等需要跨端同步的操作及同步序号。
- 内容清单及词包权限属于private_content_packs。

所有个人表启用RLS，仅允许auth.uid()访问自身数据。Storage同样按账户隔离。服务端高权限密钥不能进入前端、词包、导出文件或日志。学习密码由身份服务处理，不保存到项目文件。

导出JSON包含内容清单、用户学习记录和必要配置；不含密码、会话令牌或服务端密钥。恢复先预览账号、版本和记录数，再按事件ID合并；坏文件不能破坏现有数据。云同步之外提供用户主动下载备份，不把同步称为独立历史备份。

## 11. 错误与更新行为

- 网络超时：保留outbox，显示待同步，退避重试；不反复弹窗打断练习。
- 账号过期：保留数据并提示登录；认证恢复后续传。
- 词包缺失或校验不符：只阻止受影响内容；允许已有可用内容学习，并给出重新下载/导入入口。
- 音频缺失：明示不可用，跳过听辨；不因播放失败降低掌握评级。
- 数据库空间不足：停止写入下一条作答，保留当前题，提供导出和清理音频入口。
- 应用更新：有更新时在学习组结束后提示，不能在作答中强制刷新；数据库迁移先确保备份可恢复。
- 未配置云服务的本地开发环境只可标示“本地体验”，不能显示“云同步成功”。

## 12. 验收标准

自动检查可以证明保存、去重和调度规则；学习效果需要至少一周个人试用，并如实报告样本量和观察，不能承诺提升指定分数。

## 13. 分阶段交付

1. 先验证手机网络与云服务可达性，准备词包清单及一小批已检查学习内容。此阶段产出内容报告和网络验证记录。
2. 完成本地学习闭环：导入、小测、15分钟队列、作答、复习、薄弱项、导出恢复。以A1—A6、A10—A12的相应本地检查验收。
3. 接入账号、云端事件同步、权限和离线冲突处理。完成A5—A9、A13、A15的真实环境验证。
4. 真机试用，调整估时与默认任务量，逐步扩大经过校对的内容；完成A14并记录内容覆盖边界。

所有阶段以验收结果推进，不在尚未配置真实云端时宣称软件已满足同步要求。

设计评审通过后再形成实现计划；实现计划需列明具体文件、迁移、测试与部署步骤。创建外部项目、账号初始化和任何费用操作应在具体资源与费用可审阅时处理。
